# Proyek Akhir: Analisis Nilai Siswa

## Deskripsi
Aplikasi berbasis Python ini dikembangkan untuk membantu pengajar atau guru dalam mengelola, menghitung rata-rata, menyaring status kelulusan berdasarkan KKM, serta menampilkan ringkasan statistik nilai siswa secara otomatis.

## Fitur
- Penerimaan input daftar nilai siswa dengan validasi dan penanganan kesalahan (*try-except*)[cite: 5, 7, 20].
- Perhitungan rata-rata kelas otomatis.
- Penentuan status kelulusan siswa secara objektif (Konstanta `BATAS_LULUS = 60`)[cite: 5, 6].
- Penyajian ringkasan statistik lengkap (jumlah siswa, nilai minimum, nilai maksimum, dan total siswa lulus).

## Persyaratan
- Python 3.x

## Cara Menjalankan
Buka terminal di VS Code, lalu jalankan perintah berikut[cite: 4, 8]:
```bash
python3 main.py
